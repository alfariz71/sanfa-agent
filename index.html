Download Sanfa-Agent-Setup.exe (~89 MB)
Murni 1 file installer (.exe) resmi — tanpa ekstrak ZIP, tanpa install Node.js terpisah!
Buka PowerShell di laptopmu lalu jalankan 1 perintah ini:
del "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup\SanfaBridge.vbs" -Force -ErrorAction SilentlyContinue; Stop-Process -Name "node" -ErrorAction SilentlyContinue
Perintah ini akan langsung menghapus auto-start dan menghentikan background bridge di laptopmu.
Cara mematikan auto-start pada paket ZIP Portable:
1. Buka folder hasil ekstrak Sanfa-Bridge-CLI di laptopmu.
2. Cukup double-klik file uninstall-bridge-startup.bat.
3. Selesai! Auto-start langsung terhapus dan proses bridge otomatis berhenti.
Cara mematikan auto-start pada aplikasi desktop:
1. Buka Task Manager (tekan Ctrl + Shift + Esc) → pilih tab Startup.
2. Cari Sanfa Agent → klik kanan → pilih Disable.
• Untuk keluar langsung: klik kanan ikon Sanfa di tray taskbar (kanan bawah) → Keluar.
Catatan: Mematikan auto-start ini akan membuat bridge harus diaktifkan secara manual saat ingin menghubungkan laptop.

Buku Panduan Sanfa Agent
Perintah Cepat (Slash Commands)
Ketik karakter / pada kolom obrolan untuk memunculkan menu pintasan otomatis. Berikut daftar perintah yang siap digunakan:
Perintah Fungsi & Contoh Penggunaan
/prefer [aturan] Melatih memori jangka panjang AI tentang aturan atau preferensimu.
Contoh: /prefer selalu jawab singkat dan padat
/panggilan [nama] Mengubah nama panggilan akrab yang dipakai AI untuk menyapamu.
Contoh: /panggilan Bang Ikhsan
/imagine [prompt] Menghasilkan gambar ilustrasi AI menggunakan Google Imagen 3.
Contoh: /imagine pemandangan senja cyberpunk
/model [nama] Mengganti model AI yang aktif tanpa perlu membuka modal picker.
Contoh: /model claude-3-5-sonnet
/clear Membersihkan riwayat percakapan sesi ini untuk memulai topik baru.
/help Menampilkan daftar perintah dan tombol bantuan cepat di jendela chat.
Menghubungkan Laptop ke Sanfa Agent
Dengan Sanfa Bridge aktif, AI bisa membaca hardware laptop (RAM & Baterai), mengontrol mouse/keyboard, dan menjalankan instruksi terminal secara langsung.
Visual Panduan — Interface Sanfa Bridge
TANDA 1
Pilih Tab "Desktop App" (Sangat Disarankan)
Di tab Pengaturan → Bridge, klik tombol Desktop App. Cukup download Sanfa-Agent-Setup.exe (~89 MB) dan dobel-klik untuk memasang. Tanpa perlu install Node.js!
TANDA 2
Otentikasi Token Otomatis
Saat aplikasi desktop dibuka dan kamu login dengan username & passwordmu, Bridge token di laptopmu akan otomatis disinkronkan tanpa perlu salin-tempel kode manual.
TANDA 3
Indikator Lampu Hijau "Bridge Terhubung"
Perhatikan kartu status atas: saat lampu dot menyala hijau dengan status Bridge Terhubung: Laptop-Nama, artinya laptopmu sudah 100% online dan siap menerima perintah!
Tips Tambahan (Bagi Pengguna Terminal): Kamu juga bisa menjalankan perintah 1-baris PowerShell di tab Terminal jika laptopmu sudah terpasang Node.js LTS.
Kloning Persona dari WhatsApp
Sanfa Agent bisa mempelajari rekaman obrolan WhatsApp untuk menduplikasi gaya bicara, slang, lelucon khas, dan memori masa lalu kontak yang kamu inginkan.
1
Buka Chat di Aplikasi WhatsApp HP
Buka percakapan obrolan (pribadi atau grup) dengan orang yang ingin kamu tiru kepribadiannya di aplikasi WhatsApp Android atau iPhone kamu.
2
Buka Menu "Ekspor Chat" (Export Chat)
Ketuk menu titik tiga (⋮) di pojok kanan atas layar obrolan → ketuk Lainnya (More) → pilih Ekspor Chat (Export Chat).
3
PENTING: Pilih Opsi "Tanpa Media" (Without Media)
WhatsApp akan menanyakan apakah ingin menyertakan media. Wajib pilih 'Tanpa Media' agar menghasilkan berkas teks .txt atau .zip yang ringan, bersih, dan cepat diproses oleh AI.
4
Upload & Mulai Roleplay di Sanfa Agent
Kirim berkas .txt tersebut ke laptopmu, lalu di Sanfa Agent klik tombol Persona WA di topbar → upload berkas → klik Generate Kloning. Aktifkan sakelar Roleplay, dan Sanfa akan berbicara persis seperti kontak tersebut!

====================================================
SANFA BRIDGE — CLI Portable Package
Versi: 2.0 | sanfaagent.my.id
====================================================

Paket ini berisi semua file yang dibutuhkan untuk
menjalankan Sanfa Bridge di laptop kamu tanpa perlu
install aplikasi apapun (hanya butuh Node.js).

====================================================
CARA PAKAI (PILIH SALAH SATU):
====================================================

CARA 1 — Double-klik (Paling mudah)
--------------------------------------
1. Ekstrak folder ini ke mana saja (misal: Desktop)
2. Double-klik file: run-bridge.bat
3. Masukkan token kamu saat diminta
4. Bridge langsung terhubung!

CARA 2 — Terminal / CMD (1 Perintah)
--------------------------------------
Buka Terminal / PowerShell, lalu jalankan:

  node sanfa-bridge.mjs --token TOKENMU

Ganti TOKENMU dengan token yang ada di profil kamu
di sanfaagent.my.id (klik avatar → Profil).

CARA 3 — Auto-Start saat Windows menyala
--------------------------------------
Double-klik: install-bridge-startup.bat
Setelah itu, setiap laptop dinyalakan Bridge
langsung berjalan otomatis di background.

====================================================
BUTUH NODE.JS?
====================================================
Download gratis dari: https://nodejs.org
Atau via terminal: winget install OpenJS.NodeJS.LTS
